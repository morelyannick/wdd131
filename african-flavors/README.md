# African Flavors – Discover African Cuisine

Projet final de développement web en HTML, CSS et JavaScript vanilla.

## Objectif
Créer un site éducatif et interactif sur la cuisine africaine, avec :
- 10 pays
- 60 plats détaillés
- recherche et filtre
- favoris en localStorage
- conversion de devises
- formulaire de contact

## Structure
- `index.html` : page d'accueil
- `countries.html` : page des pays et des plats
- `favorites.html` : page des favoris
- `references.html` : page des références
- `css/style.css` : style principal
- `js/data.js` : données des plats et pays
- `js/main.js` : logique JavaScript

## Instructions
Ouvrir `index.html` dans le navigateur pour commencer.
